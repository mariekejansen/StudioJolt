# StudioJolt

StudioJolt enables real-time, cloud-based development of scalable, high-performance services through dynamic auto-scaling and parallel processing.

StudioJolt is aimed at developers who need a straightforward, dependable solution.

- rust

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/StudioJolt.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure StudioJolt, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
